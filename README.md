# house-price-prediction-ml
House Price Prediction project using Machine Learning with Python, Pandas, Scikit-learn, Linear Regression, and Random Forest Regression.
This project predicts house prices using Machine Learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Models Used
- Linear Regression
- Random Forest Regressor

## Features
- Data Cleaning
- Missing Value Handling
- Categorical Encoding
- Model Training
- Model Evaluation
- Data Visualization

## Evaluation Metrics
- MAE
- RMSE
- R² Score
